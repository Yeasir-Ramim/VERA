OPTION 1: Train on Real APTOS Dataset (RECOMMENDED)
----------------------------------------------------
Time needed: 
  - Download: 15 minutes (3.6 GB)
  - Training: 4 hours on GPU / 16 hours on CPU
  - Results: State-of-the-art performance (Kappa 0.82-0.87)

Steps:
1. Install Kaggle API:
   pip install kaggle

2. Get Kaggle credentials:
   - Visit: https://www.kaggle.com/settings
   - Click "Create New API Token"
   - Save kaggle.json to C:\Users\<YourUsername>\.kaggle\

3. Download APTOS:
   kaggle competitions download -c aptos2019-blindness-detection -p data/raw/aptos2019/
   cd data/raw/aptos2019
   tar -xf train_images.zip
   cd ../../..

4. Start training:
   Double-click: train_quick.bat
   Or run: python train.py --dataset aptos --epochs 50 --backbone efficientnet_b3

5. Wait for training to complete (~4 hours)

6. Evaluate:
   python evaluate.py --checkpoint checkpoints/production_model/best_model.pth

7. Deploy:
   streamlit run app.py

================================================================================
TROUBLESHOOTING
================================================================================

Q: "I don't have a Kaggle account"
A: Create one free at https://www.kaggle.com (takes 2 minutes)

Q: "Kaggle API not working"
A: Make sure kaggle.json is in C:\Users\<YourUsername>\.kaggle\

Q: "Download too slow"
A: Download manually from https://www.kaggle.com/c/aptos2019-blindness-detection/data

Q: "Not enough disk space"
A: Need 3.6 GB for APTOS. Delete unnecessary files or use external drive.

Q: "CUDA out of memory"
A: Reduce batch size: python train.py --batch_size 16 (or 8)

Q: "Training too slow on CPU"
A: Use smaller model: python train.py --backbone resnet18 --epochs 10
